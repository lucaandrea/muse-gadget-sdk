# Reply typography

The three Montserrat 20 px style files provide bold, italic and bold italic
for Markdown replies. Source fonts are Montserrat-Bold.ttf,
Montserrat-MediumItalic.ttf and Montserrat-BoldItalic.ttf from
https://github.com/JulietaUla/Montserrat/tree/master/fonts/ttf.
See Montserrat-OFL.txt for the SIL Open Font License.

Generated using lv_font_conv 1.5.3, size 20, 4 bpp, range 0x20–0xff,
additional characters •…, no compression and no kerning. The command is
recorded at the top of each generated file. The generated include is changed
to "lvgl.h" to match the IDF component include path. The existing CJK font
remains the fallback.
